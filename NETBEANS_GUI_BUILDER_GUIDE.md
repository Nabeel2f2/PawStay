# NetBeans GUI Builder quick guide

Open the Maven project folder in Apache NetBeans. Expand `Source Packages` → `com.mycompany.boarding_center`.

These Java files have corresponding `.form` metadata in the same package and are intended to open in the visual editor:

| Screen | Java file | Form metadata |
|---|---|---|
| Login | `design.java` | `design.form` |
| Dashboard | `dashboard.java` | `dashboard.form` |
| Customers | `Customers.java` | `Customers.form` |
| Pets | `Pets.java` | `Pets.form` |
| Reservations | `reserve.java` | `reserve.form` |
| Staff | `Staff.java` | `Staff.form` |
| Billing | `Billing.java` | `Billing.form` |
| Display board | `display_board.java` | `display_board.form` |

Open a Java file and select **Design** beside **Source** and **History**. A visible Design tab depends on NetBeans recognising both the Java source and its valid matching `.form` file. Keep those files together when copying or submitting the project.

For an honest coursework demonstration, show the actual component tree, palette and properties, and explain the layout/event handlers you understand. Do not claim that work was exclusively hand-built if that would be inaccurate.
